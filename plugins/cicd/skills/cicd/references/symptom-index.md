# Índice de sintomas — Quick Troubleshooting

Tabela de triagem: sintoma → causa provável → solução, com o arquivo e a seção do detalhe. Leia
quando tiver uma mensagem de erro ou um sintoma concreto em mãos. Procure pela string do erro
(`grep -n '<trecho>' symptom-index.md`) em vez de ler a tabela inteira.

- Tags: `[S]` compartilhado, `[B]` só backend, `[F]` só frontend.
- Os arquivos citados nas células (`troubleshooting-shared.md`, `self-hosted-runner-docker.md`,
  `cd-pipeline-pitfalls.md` etc.) são roteados direto pelo SKILL.md; abra só a seção indicada.
- "lesson N" / "lição N" é a linha N de `lessons-learned.md`, também roteado pelo SKILL.md.
